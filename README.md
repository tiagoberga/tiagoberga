## 👨‍💻 Sobre mim

Profissional de TI com **15 anos de experiência** em desenvolvimento de sistemas corporativos, gestão de projetos de TI, liderança técnica e infraestrutura. Trajetória construída desde o desenvolvimento de software até a **coordenação estratégica de soluções críticas** para os segmentos industrial e comercial.

Perfil **hands-on com visão estratégica**: transito naturalmente entre arquitetura de software, desenvolvimento backend (**Java/Spring Boot**), frontend (**Vue.js/PrimeVue**), banco de dados (**PostgreSQL**), infraestrutura (**Docker/Linux**), DevOps, CI/CD e sistemas fiscais (**NF-e/NFC-e/SEFAZ**).

Atualmente focado em soluções fiscais modernas, integrações ERP, automação de processos corporativos e aplicação prática de **IA para produtividade e documentação técnica**.

## 🧩 Projetos em Destaque

<details>
<summary><b>🧾 Sistema de Emissão NF-e &nbsp;|&nbsp; Arquiteto e Desenvolvedor</b></summary>
<br/>

Sistema fiscal completo com arquitetura **local-first**, completamente desacoplado do ERP legado (dual datasource). Cobre todo o ciclo da NF-e: emissão, cancelamento, carta de correção, eventos fiscais e geração de DANFE. Inclui dashboard fiscal, monitoramento com Prometheus + Grafana, CI/CD automatizado e documentação técnica.

`Java 21` `Spring Boot 3` `Spring Security` `JWT` `PostgreSQL` `Flyway` `Vue 3` `TypeScript` `PrimeVue 4` `Docker` `GitHub Actions` `NF-e 4.00` `SEFAZ` `DANFE` `BouncyCastle` `JAXB` `Prometheus` `Grafana`

</details>

<details>

Middleware de integração com serviços DDA dos bancos para centralizar e automatizar **contas a pagar**, com dashboards de previsão de pagamentos em lotes e API REST para integração com ERPs.

`Spring Boot` `PostgreSQL` `DDA Bancário` `APIs REST` `Vue 3` `Automação Financeira` `Docker`

</details>
