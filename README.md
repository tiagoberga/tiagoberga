<summary><b>🧾&nbsp; Sistema de Emissão NF-e &nbsp;—&nbsp; Arquiteto e Desenvolvedor</b></summary>
<br/>

Sistema fiscal completo com arquitetura **local-first**, desacoplado do ERP legado via dual datasource. Cobre todo o ciclo da NF-e: emissão, cancelamento, carta de correção, eventos fiscais e geração de DANFE. Inclui dashboard fiscal, monitoramento com Prometheus + Grafana e CI/CD automatizado.

`Java 21` `Spring Boot 3` `Spring Security` `PostgreSQL` `Flyway` `Vue 3` `TypeScript` `PrimeVue 4` `Docker` `GitHub Actions` `NF-e 4.00` `SEFAZ` `DANFE` `BouncyCastle` `JAXB` `Prometheus` `Grafana`

</details>
